# Weather Forecast

Статический сайт прогноза погоды: текущая погода + 5 дней вперёд, по названию города или геолокации.

## Источник данных
[Open-Meteo](https://open-meteo.com) — открытый бесплатный API без ключа:
- Geocoding API — превращает название города в координаты
- Forecast API — погода по координатам

## Возможности
- Поиск по названию города
- Определение погоды по геолокации браузера
- Текущая температура, ветер, описание
- Прогноз на 5 дней (мин/макс температура)

## Запуск
Чистый HTML/CSS/JS, без сборки — просто открой `index.html` в браузере.

## Технологии
HTML, CSS, JavaScript (fetch API), без фреймворков.
